# AiSDR Database Migrations

This directory contains all database schema migrations for AiSDR.

## Structure

```text
migrations/
│
├── env.py
├── script.py.mako
├── versions/
└── README.md
```

## Generate a Migration

```bash
alembic revision --autogenerate -m "create initial schema"
```

## Apply Latest Migration

```bash
alembic upgrade head
```

## Rollback One Migration

```bash
alembic downgrade -1
```

## Rollback All Migrations

```bash
alembic downgrade base
```

## View Migration History

```bash
alembic history
```

## Show Current Database Revision

```bash
alembic current
```

## Migration Guidelines

- One logical change per migration.
- Never edit an applied migration.
- Create a new migration for schema changes.
- Keep migrations deterministic and reversible.
- Review autogenerated migrations before committing.

## Naming Convention

Examples:

- create_lead_table
- create_assessment_table
- add_company_size_column
- create_ai_request_indexes
- add_recommendation_status

## Version Control

Migration files are source code and must be committed to Git.

Do not delete or modify previously released migrations.
