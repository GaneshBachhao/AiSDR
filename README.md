projects:

  See `Backend/README.md` for setup, and `Backend/docs/` for the product
  backlog, sprint plan, and architecture doc.
- **[`Frontend/`](Frontend/)** — Angular application (TypeScript). See
  `Frontend/README.md` for setup. Currently exploratory/untracked in
  project planning terms — see `Backend/docs/product_backlog.md` for what
  *is* formally scheduled.

Restructured into this single-repo `Backend/` + `Frontend/` layout on
